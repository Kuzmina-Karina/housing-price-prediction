# Прогнозирование стоимости недвижимости

Учебный проект по анализу данных и машинному обучению. Модель прогнозирует стоимость недвижимости по характеристикам объекта: площади, количеству комнат, состоянию, году постройки и расположению.

## Что сделано в ноутбуке

- Проверены типы данных, пропуски и дубликаты.
- Исследованы распределение цен и связь признаков со стоимостью недвижимости.
- Добавлены два признака: наличие ремонта и отношение жилой площади к площади участка.
- Обучена модель `HistGradientBoostingRegressor` с логарифмированием целевой переменной.
- Оценены качество прогноза, остатки и важность признаков на тестовой выборке.
- Сохранены модель и список признаков для дальнейшего использования.

В проект также входят скрипт обучения, сервис на FastAPI для одиночных и пакетных предсказаний, тесты API и Dockerfile.

**Стек:** Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, FastAPI, Docker.

## Данные и результаты

В проекте используется учебный датасет из материалов практики: **104 000 записей, 21 исходный столбец**. Целевая переменная — `price`. Данные находятся в [buildings_prices.csv](data/table-data/buildings_prices.csv).

Результаты, сохранённые в [ноутбуке](notebooks/Project_Kuzmina.ipynb), получены при разделении данных на обучающую и тестовую выборки в соотношении 80/20 (`random_state=42`):

| Метрика | Значение |
|---|---:|
| MAE | 130 646,29 |
| RMSE | 222 813,10 |
| R² | 0,6223 |

MAE и RMSE приведены в единицах стоимости из датасета. Это результаты модели из ноутбука; скрипт `src/train.py` обучает отдельную модель на всём датасете.

## Запуск

Рекомендуется Python 3.11 или 3.12. Все команды выполняются из корня репозитория.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Ноутбук

```bash
jupyter notebook notebooks/Project_Kuzmina.ipynb
```

Запускайте ячейки последовательно. Ноутбук читает данные из `../data/table-data/` и сохраняет модель в `../models/`.

### API

```bash
uvicorn src.api:app --reload --port 8000
```

Документация с примерами запросов: <http://localhost:8000/docs>.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | Состояние сервиса и модели |
| POST | `/predict` | Прогноз для одного объекта |
| POST | `/predict/batch` | Прогноз для группы объектов |

Примеры запросов и запуск через Docker:

```bash
bash scripts/test_request.sh
docker build -t housing-price-api .
docker run --rm -p 8000:8000 housing-price-api
```

### Тесты

```bash
python -m pytest -q
```

Тесты проверяют ответы API, загрузку сохранённой модели и восстановление цены для модели из ноутбука.
